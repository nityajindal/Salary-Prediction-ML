# Salary Prediction Using Machine Learning

## 1. Project Overview
This project predicts the salary of a person based on their age and years of work experience using Machine Learning.

## 2. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 3. Dataset
The dataset contains 30 records with three columns:
- YearsExperience
- Age
- Salary

## 4. Data Analysis
Data cleaning and exploratory data analysis were performed.
Four graphs were created to understand the relationship between the features.

## 5. Machine Learning Algorithm
Linear Regression was used to predict salaries.

## 6. Model Evaluation
The model was evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R2 Score

Baseline Model R2 Score: 0.8852

Improved Model R2 Score: 0.8811

The Baseline Model performed slightly better.

## 7. Sample Prediction
Age: 28
Years of Experience: 5

Predicted Salary: 75688.57

## 8. Conclusion

The project successfully predicts salary based on age and work experience using Linear Regression.
